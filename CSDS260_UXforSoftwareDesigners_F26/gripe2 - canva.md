  * FOR-WHOM-BAD: People with multiple Canva accounts (ex. personal, school/company account).
  * FOR-WHOM-OK: Users with a singular account.
  * WHAT:  Canva is a free-to-use online graphic design tool. Let's say you have 2 accounts. When you're logged in on account A but you click a file shared only to file B, it says "We can't show this page" and that the user must "take a few moments to log in with the correct account". I have to manually type in canva.com on another tab, log out on existing account, then log in on the account in which the file is shared. My main problem here is not access but rather the excessiveness of having to manually log in/log out when if this happens on other word/image processing app, it will simply say "You need access"/ request access or ask if you want to sign in as another email.
