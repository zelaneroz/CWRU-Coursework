# CWRU-Coursework

A centralized repository for my coursework, lecture notes, and projects from my time at Case Western Reserve University (Aug 2024 - Present)

### **Repository Structure**

My coursework is organized in a flat structure, with each top-level folder representing a course. The naming convention is `COURSEID_Description_SemesterYear` for quick access and searchability.

For example:
- `CSDS233_DataStructures_F24`
- `CSDS340_Algorithms_F25`
